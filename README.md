# Croqui de Perfuração — atualizações

Este repositório guarda só a versão mais recente do programa **Croqui de Perfuração** (Fagundes), usada pelo menu **☰ Arquivo › ⟳ Atualizar aplicativo**.

- `versao.txt` — linha 1: número da versão; demais linhas: o que mudou.
- `CroquiPerfuracao.exe` — o programa (motor) daquela versão.

O código-fonte não fica aqui.
